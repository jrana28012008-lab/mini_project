# ⚡ Electricity Bill Simulator

A simple Python mini-project that simulates and calculates electricity bills based on user inputs and predefined tariff slabs.

## 🚀 Features
* *Interactive Input:* Prompts the user to enter meter readings or total units consumed.
* *Slab-Wise Calculation:* Automatically calculates costs based on different price brackets per unit.
* *Detailed Breakdown:* Displays a clean summary of the fixed charges, unit costs, and final total bill.

## 🛠️ How It Works
The program takes the total units consumed during the billing cycle and applies standard progressive pricing rules. For example:
* Up to 100 units: Low rate
* Above 100 units: Higher rate
